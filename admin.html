Categorias do cardápio

A ordem abaixo define a ordem de exibição no site. Categorias com produtos não podem ser removidas — oculte ou mova os produtos antes.

    Exportar cardápio

    Baixe um arquivo .json com todos os produtos e categorias atuais. Guarde este arquivo como backup.

    Importar cardápio

    Selecione um arquivo .json exportado anteriormente para restaurar o cardápio. Isso substitui os dados atuais salvos neste navegador.

    Restaurar cardápio padrão

    Apaga tudo que foi salvo neste navegador e volta o cardápio para os produtos de exemplo iniciais.

    Novo produto

    Cole o link de uma imagem já hospedada (ex: Imgur, Drive público) ou coloque o arquivo na pasta /img e escreva o caminho, ex: img/classico.jpg. Também é possível enviar um arquivo do computador abaixo.
